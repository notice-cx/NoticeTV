Choose what it shows

Every setting lives in one file on the box

/etc/noticetv/noticetv.conf 
DASHBOARD_URL=https://example.com/wall   # the page on screen
DISPLAY_SCALE=2                          # how large it draws
POWER_PROFILE=fanless                    # for boxes without a fan
STATUSBAR=yes                            # the bar in the corner
Then apply it:/opt/noticetv/install.sh
